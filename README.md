# Wiegand's Michigan Tree Finder — POC v7

## Photo upgrade
- Every database entry now has a photo-source lookup path.
- Existing whole-tree representative photos are retained.
- Exact verified cultivar photos were added where found, including Crimson King Maple and Limelight Hydrangea.
- The result card includes a View photo source button.
- Photo priority is: exact cultivar + whole tree, then species + whole tree, then clearly labeled representative image.
- Wiegand's photography can replace these reference images later without changing the app architecture.

## Important
Wikimedia Commons files have individual licenses shown on each file page. Before production/public marketing use, each selected image should be reviewed for its specific attribution/license requirements.
